<h2><a href="https://www.geeksforgeeks.org/problems/k-closest-points-to-origin--172242/1">K Closest Points to Origin</a></h2><h3>Difficulty Level : Difficulty: Medium</h3><hr><div class="problems_problem_content__Xm_eO" style="user-select: auto;"><p style="user-select: auto;"><span style="font-size: 14pt; user-select: auto;">Given an array of points where each point is represented as <strong style="user-select: auto;">points[i] = [x<sub style="user-select: auto;">i</sub>, y<sub style="user-select: auto;">i</sub>]</strong> on the X-Y plane and an integer <strong style="user-select: auto;">k</strong>, return the k closest points to the origin (0, 0).</span></p>
<p style="user-select: auto;"><span style="font-size: 14pt; user-select: auto;">The distance between two points on the X-Y plane is the Euclidean distance, defined as:&nbsp;</span></p>
<p style="text-align: center; user-select: auto;"><span style="font-size: 14pt; user-select: auto;"><strong style="user-select: auto;">sqrt( (x<sub style="user-select: auto;">2</sub> - x<sub style="user-select: auto;">1</sub>)<sup style="user-select: auto;">2</sup> + (y<sub style="user-select: auto;">2</sub> - y<sub style="user-select: auto;">1</sub>)<sup style="user-select: auto;">2</sup> )</strong></span></p>
<p style="user-select: auto;"><span style="font-size: 14pt; user-select: auto;">Note: You can return the <strong style="user-select: auto;">k</strong> closest points in any order, driver code will sort them before printing.</span></p>
<p style="user-select: auto;"><span style="font-size: 14pt; user-select: auto;"><strong style="user-select: auto;">Examples:</strong></span></p>
<pre style="user-select: auto;"><span style="font-size: 14pt; user-select: auto;"><strong style="user-select: auto;">Input:</strong> k = 2, points[] = [[1, 3], [-2, 2], [5, 8], [0, 1]]</span><br style="user-select: auto;"><span style="font-size: 14pt; user-select: auto;"><strong style="user-select: auto;">Output:</strong> [[-2, 2], [0, 1]]</span><br style="user-select: auto;"><span style="font-size: 14pt; user-select: auto;"><strong style="user-select: auto;">Explanation:</strong> The Euclidean distances from the origin are:</span><br style="user-select: auto;"><span style="font-size: 14pt; user-select: auto;">Point (1, 3) = sqrt(10)</span><br style="user-select: auto;"><span style="font-size: 14pt; user-select: auto;">Point (-2, 2) = sqrt(8)</span><br style="user-select: auto;"><span style="font-size: 14pt; user-select: auto;">Point (5, 8) = sqrt(89)</span><br style="user-select: auto;"><span style="font-size: 14pt; user-select: auto;">Point (0, 1) = sqrt(1)</span><br style="user-select: auto;"><span style="font-size: 14pt; user-select: auto;">The two closest points to the origin are [-2, 2] and [0, 1].</span></pre>
<pre style="user-select: auto;"><span style="font-size: 14pt; user-select: auto;"><strong style="user-select: auto;">Input:</strong> k = 1, points = [[2, 4], [-1, -1], [0, 0]]</span><br style="user-select: auto;"><span style="font-size: 14pt; user-select: auto;"><strong style="user-select: auto;">Output:</strong> [[0, 0]]</span><br style="user-select: auto;"><span style="font-size: 14pt; user-select: auto;"><strong style="user-select: auto;">Explanation: </strong>The Euclidean distances from the origin are:</span><br style="user-select: auto;"><span style="font-size: 14pt; user-select: auto;">Point (2, 4) = sqrt(20)</span><br style="user-select: auto;"><span style="font-size: 14pt; user-select: auto;">Point (-1, -1) = sqrt(2)</span><br style="user-select: auto;"><span style="font-size: 14pt; user-select: auto;">Point (0, 0) = sqrt(0)</span><br style="user-select: auto;"><span style="font-size: 14pt; user-select: auto;">The closest point to origin is (0, 0).</span></pre>
<p style="user-select: auto;"><span style="font-size: 14pt; user-select: auto;"><strong style="user-select: auto;">Constraints:</strong></span></p>
<ul style="user-select: auto;">
<li style="user-select: auto;"><span style="font-size: 14pt; user-select: auto;">1 &lt;= k &lt;= points.size() &lt;= 10<sup style="user-select: auto;">5</sup></span></li>
<li style="user-select: auto;"><span style="font-size: 14pt; user-select: auto;">-10<sup style="user-select: auto;">4</sup> &lt;= x<sub style="user-select: auto;">i</sub>, y<sub style="user-select: auto;">i</sub> &lt;= 10<sup style="user-select: auto;">4</sup></span></li>
