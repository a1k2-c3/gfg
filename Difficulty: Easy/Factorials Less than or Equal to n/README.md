<pre style="user-select: auto;"><strong style="user-select: auto;"><span style="font-size: 18px; user-select: auto;">Input: </span></strong><span style="font-size: 18px; user-select: auto;">n = 6</span>

So we print only first three factorial numbers.</span></pre>
